# Contribution policy

Contributions should come as a pull request submitted to the Git repository. 

Contributions are encouraged and always welcome, but please should make sure of the following:

* Your contributions pass the automated test suite (`pytest`).
* Where appropriate, you include new tests for any new functionality added by you contributions.
* Your contributions include docstrings in the Sphinx/reStructuredText style that pass the inbuilt style checks. 
* Your contributions are formatted with the `ruff` formatter and pass the `ruff` style checks. 
* Your contributions are fully documented with required text added to `./docs`. 
* Declare the use of AI-assisted development. 


## Human oversight and autonomous contributions

Fully autonomous contributions to the main branches of this repository are not permitted unless explicitly approved in advance by maintainers.

All pull requests must be submitted by a human operator who:

* Has reviewed and understands the proposed changes.
* Takes responsibility for the correctness of the submitted changes.
* Can explain the changes during the review process.

AI-assisted development tools may be used to support contributions, but we place the onus on the human making the pull request to have reviewed, understood, and verified the submitted changes in pull request.

The project maintainers reserve the right to reject contributions that do not meet these requirements.
